Pen Library

An independent, open-source Android utility for managing tiptoi book audio over USB.

Browse the German catalog, install books, free space with verified backups, and manage several pens. No account or charging-station Wi-Fi needed.

App interface in English, German and French. Requires a compatible USB mass-storage pen, a data cable and an Android phone that supports USB storage. Physical testing so far covers a fourth-generation pen.
